# 00 · 项目总览与目录规划

> 本文档是开发参考的索引，说明项目定位、技术栈、目录结构、里程碑与开发约定。
> 各功能模块的详细实现目标与开发过程见 `01` ~ `06` 文档。

## 一、项目定位

构建一个 Agent：**连接业务 MySQL → 采集库表结构 → 自动写入自建元数据库 → 用 LLM 补全业务元数据（注释、业务域、敏感标记）**，最终产出可用的数据字典。

## 五、开发约定（务必遵守）

1. **全异步**：所有涉及数据库/网络 IO 的函数一律 `async def`，用 SQLAlchemy async 引擎，禁止混入同步 `pymysql`。
2. **生命周期分离**：`mysql_client_manager.init()/close()` 由**入口**（`agent/main.py` 的编排函数）统一负责；service/repo/collector 只做业务，不管理引擎生命周期。
3. **单例模式**：共享服务（如 `database_service`）做成模块级单例，与现有 `mysql_client_manager` 风格一致。
4. **配置集中**：新增连接配置（metadata_db、多实例）走 `config_yaml/conf.yaml` + `client_conf.py` 结构体，不在代码里硬编码。
5. **标识符安全**：库名/表名/列名等 SQL 标识符无法走绑定参数，拼接前必须用反引号包裹 + 校验（参考 `database_service.get_tables`）。
6. **软删除**：元数据删除一律 `is_deleted=1`，不物理删除。
7. **分阶段提交**：按 M1→M6 顺序落地，每个里程碑能独立运行验证，再进入下一个。
