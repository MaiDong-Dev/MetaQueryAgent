# 01 · M1 技术元数据采集

## 一、实现目标

1. 创建自建元数据库 `metadata_db` 及核心表；
2. 实现采集器：连接业务 MySQL，读取 `information_schema`，输出结构化技术元数据；
3. 把采集结果写入元数据库；
4. 过滤系统库 `information_schema / mysql / sys / performance_schema`。

**本期不涉及 LLM、不涉及增量比对**，先把「采集 → 落库」链路跑通。

### 验收标准
- 能对指定业务库，采集出 库/表/字段/索引 四级技术元数据；
- 数据准确写入 `md_instance / md_database / md_table / md_column / md_index`；
- 系统库被正确排除；
- 重复执行不报错（幂等，暂以"全量覆盖/插入"处理）。

## 二、详细开发过程

### 步骤 1：建元数据表（`sql/001_create_metadata_tables.sql`）

新建 `sql/` 目录，写入以下 DDL（MySQL 8，utf8mb4）：

```sql
CREATE DATABASE IF NOT EXISTS metadata_db
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

USE metadata_db;

-- 实例配置
CREATE TABLE md_instance (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  instance_name VARCHAR(128) NOT NULL COMMENT '实例名称，如 supply_chain',

  remark        VARCHAR(512) NULL,
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_instance_name (instance_name)
) COMMENT='业务 MySQL 实例配置';

-- 库
CREATE TABLE md_database (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  instance_id   BIGINT UNSIGNED NOT NULL,
  database_name VARCHAR(128) NOT NULL,
  charset       VARCHAR(64)  NULL,
  collation     VARCHAR(64)  NULL,
  comment       VARCHAR(512) NULL,
  is_deleted    TINYINT NOT NULL DEFAULT 0,
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_db (instance_id, database_name)
) COMMENT='库技术元数据';

-- 表
CREATE TABLE md_table (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  instance_id   BIGINT UNSIGNED NOT NULL,
  database_name VARCHAR(128) NOT NULL,
  table_name    VARCHAR(128) NOT NULL,

  engine        VARCHAR(64)  NULL,
  table_comment VARCHAR(512) NULL,
  charset       VARCHAR(64)  NULL,
  collation     VARCHAR(64)  NULL,
  is_deleted    TINYINT NOT NULL DEFAULT 0,
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_table (instance_id, database_name, table_name)
) COMMENT='表技术元数据';

-- 字段
CREATE TABLE md_column (
  id                BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  instance_id       BIGINT UNSIGNED NOT NULL,
  database_name     VARCHAR(128) NOT NULL,
  table_name        VARCHAR(128) NOT NULL,
  column_name       VARCHAR(128) NOT NULL,
  ordinal_position  INT NULL,
  column_default    TEXT NULL,
  is_nullable       VARCHAR(8)  NULL,
  data_type         VARCHAR(64) NULL,
  column_type       VARCHAR(128) NULL COMMENT '如 varchar(64)',
  char_max_length   BIGINT NULL,
  numeric_precision BIGINT NULL,
  numeric_scale     BIGINT NULL,
  charset           VARCHAR(64) NULL,
  collation         VARCHAR(64) NULL,
  column_extra      VARCHAR(128) NULL COMMENT 'auto_increment / generated',
  column_comment    VARCHAR(512) NULL,
  is_deleted        TINYINT NOT NULL DEFAULT 0,
  created_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_column (instance_id, database_name, table_name, column_name)
) COMMENT='字段技术元数据';

-- 索引
CREATE TABLE md_index (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  instance_id   BIGINT UNSIGNED NOT NULL,
  database_name VARCHAR(128) NOT NULL,
  table_name    VARCHAR(128) NOT NULL,
  index_name    VARCHAR(128) NOT NULL,
  non_unique    TINYINT NOT NULL,
  seq_in_index  INT NOT NULL,
  column_name   VARCHAR(128) NULL,
  index_type    VARCHAR(32)  NULL,
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_index (instance_id, database_name, table_name, index_name, seq_in_index)
) COMMENT='索引元数据';
```

> 说明：`md_database / md_table / md_column` 三表用 `(instance_id, database_name, table_name[, column_name])` 作为唯一键，这是 M2 增量比对的基础。

### 步骤 3：采集器（`agent/collector/schema_collector.py`）

核心：查询 `information_schema`，组装结构化结果。数据模型用 `pydantic`（本次即可引入）：

```python
from pydantic import BaseModel

class ColumnMeta(BaseModel):
    column_name: str
    ordinal_position: int | None = None
    column_default: str | None = None
    is_nullable: str | None = None
    data_type: str | None = None
    column_type: str | None = None
    char_max_length: int | None = None
    numeric_precision: int | None = None
    numeric_scale: int | None = None
    charset: str | None = None
    collation: str | None = None
    column_extra: str | None = None
    column_comment: str | None = None

class TableMeta(BaseModel):
    database_name: str
    table_name: str
    table_type: str | None = None
    engine: str | None = None
    table_comment: str | None = None
    charset: str | None = None
    collation: str | None = None
    columns: list[ColumnMeta] = []

class DatabaseMeta(BaseModel):
    database_name: str
    charset: str | None = None
    collation: str | None = None
    comment: str | None = None
    tables: list[TableMeta] = []
```

采集 SQL（按库过滤，避免一次拉全量）：

```python
# 库
SELECT schema_name, default_character_set_name, default_collation_name, sql_path
FROM information_schema.schemata
WHERE schema_name NOT IN ('information_schema','mysql','performance_schema','sys');

# 表
SELECT table_name, table_type, engine, table_comment, table_collation
FROM information_schema.tables
WHERE table_schema = :db;

# 列
SELECT column_name, ordinal_position, column_default, is_nullable,
       data_type, column_type, character_maximum_length,
       numeric_precision, numeric_scale, character_set_name,
       collation_name, extra, column_comment
FROM information_schema.columns
WHERE table_schema = :db AND table_name = :tbl
ORDER BY ordinal_position;

# 索引
SELECT index_name, non_unique, seq_in_index, column_name, index_type
FROM information_schema.statistics
WHERE table_schema = :db AND table_name = :tbl
ORDER BY index_name, seq_in_index;
```

采集器主逻辑：

```python
class SchemaCollector:
    def __init__(self, session_factory):
        self.session_factory = session_factory

    async def collect(self) -> list[DatabaseMeta]:
        """采集所有业务库的结构"""
        async with self.session_factory() as session:
            dbs = await self._fetch_databases(session)
            result = []
            for db_name in dbs:
                tables = await self._fetch_tables(session, db_name)
                for t in tables:
                    t.columns = await self._fetch_columns(session, db_name, t.table_name)
                result.append(DatabaseMeta(database_name=db_name, tables=tables))
            return result
```

### 步骤 5：入口编排（`agent/main.py`）

```python
import asyncio
from client.mysql_client_manager import mysql_client_manager
from agent.collector.schema_collector import SchemaCollector

async def run_collect():
    mysql_client_manager.init()          # 业务库引擎
    try:
        collector = SchemaCollector(mysql_client_manager.session_factory)
        metas = await collector.collect()
        print(f"采集到 {len(metas)} 个库")
    finally:
        await mysql_client_manager.close()
```

## 三、关键注意点

- `information_schema` 采集账号只需 `SELECT` 权限，**不要用 root**；
- MySQL 8 的 `extra` 字段能区分自增/生成列，务必采全；
- 视图（`table_type='VIEW'`）没有索引/引擎，采集时要容错；
- 本期不处理增量，直接全量插入即可，但唯一键要建好，为 M2 铺路。
